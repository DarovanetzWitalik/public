## 1. Separation of Concerns (розділення структури та оформлення)
HTML-файли відповідають за структуру і зміст сторінок, а візуальне оформлення винесене в окремий файл `style.css`.

- [Спільні стилі контейнера та картки](YOUR_REPO_URL/blob/main/style.css#L8-L18)
- [Оформлення рецептного блоку](YOUR_REPO_URL/blob/main/style.css#L70-L95)

Це покращує читабельність коду та спрощує зміну зовнішнього вигляду без редагування структури HTML.

## 2. Reusability / Consistency (повторне використання спільних рішень)
Усі сторінки побудовані за єдиним шаблоном: використовується однакова навігація, однакові класи `wrapper`, `card`, `section-title`, `note`.

- [Опис повторно використовуваних CSS-класів](YOUR_REPO_URL/blob/main/style.css#L8-L39)

Завдяки цьому всі сторінки мають єдиний стиль і поводяться однаково.

У проєкті використані семантично доречні HTML-теги: заголовки, абзаци, списки, надрядкові й підрядкові індекси, горизонтальні лінії, виділення важливого тексту.
