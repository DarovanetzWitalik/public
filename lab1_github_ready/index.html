Лабораторна робота №1

Тема: Основи веб-розробки. Робота з текстом в HTML5.

Мета: ознайомлення з базовими можливостями HTML5, тегами форматування тексту, спецсимволами, списками та створенням простих веб-сторінок.

Вміст роботи
  • Завдання 1 — сторінка з тегами форматування тексту: h1-h6, p, sup, sub, hr, i, em, strong, b, span, big, small.
  • Завдання 2 — використання спецсимволів HTML та тега mark.
  • Завдання 3 — створення маркованих, нумерованих і вкладених списків.
  • Завдання 4 — сторінка за зразком із рецептом сирників.

Усі сторінки виконані у форматі HTML5 та відкриваються локально в браузері.
