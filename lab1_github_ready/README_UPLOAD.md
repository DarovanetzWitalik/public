# README_UPLOAD

## Як швидко закинути це на GitHub без консолі

1. У GitHub натисни **New repository**.
2. Вкажи назву, наприклад `lab01-web-html`.
3. Обери **Public**.
4. Натисни **Create repository**.
5. На сторінці репозиторію натисни **uploading an existing file**.
6. Перетягни вікном **усі файли з цієї папки**.
7. Напиши commit message, наприклад `Initial upload of Lab01`.
8. Натисни **Commit changes**.

## Що зробити після завантаження

1. Відкрий файл `PROGRAMMING_PRINCIPLES.md`.
2. Натисни **Edit**.
3. Замініть усі `YOUR_REPO_URL` на справжню адресу репозиторію, наприклад:
   `https://github.com/your-username/lab01-web-html`
4. Збережи зміни.
5. Створи 3 issues за текстами з файлу `GITHUB_ISSUES_AND_PRS.md`.
6. Потім створи 3 окремі PR під кожне issue.
